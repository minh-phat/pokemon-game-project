# Wildlands v2 image assets

Generated with the built-in `image_gen` tool, using the imagegen skill. Source PNGs are stored in `apps/frontend/public/assets/world-v2/`; originals remain in the Codex generated image library. The runtime atlases are produced by `scripts/build-world-assets.mjs` with alpha preserved.

## Environment props

Use case: stylized-concept. Asset type: production environment sprite atlas for an isometric pixel-art exploration game. Create a square 1536x1536 PNG with a genuinely transparent background, arranged in an exact 4 column by 4 row grid of equal 384x384 cells. Each cell contains ONE isolated full object, centered horizontally, its ground contact at 85 percent of cell height, with generous transparent padding, no object crosses a cell border. No grid lines, no text, no labels, no scene background, no ground tiles. Camera: consistent 2:1 isometric / 30 degree elevated game view. Beautiful meticulously crafted 16-bit pixel art, crisp clusters of visible square pixels, rich restrained colors, luminous warm upper-left light, cool shaded sides, dimensional volume, subtle pixel shadows only immediately at the object's feet. NOT smooth vector art, NOT photorealistic, NOT blurry. Row 1 left to right: lush broad emerald oak tree with sculpted leaf clusters and a handsome visible trunk; airy silver birch tree with pale trunk and small golden-green leaves; tall deep turquoise alpine pine; tall alpine pine laden with thick ivory snow. Row 2: graceful weeping willow with drooping mint-green foliage; small flowering tree with pink and creamy blossom clusters; rounded forest shrub with a few tiny red berries; coastal palm tree with broad arching fronds. Row 3: irregular mossy granite boulder cluster with tiny ferns; dark volcanic basalt boulders with subtle glowing orange cracks; angular blue-white glacial rock with snow; weathered fallen tree trunk covered in bright green moss and tiny mushrooms. Row 4: a tuft of tall meadow grass; delicate mixed wildflowers in lilac white and gold; a cluster of riverbank reeds and cattails; a lush curling woodland fern. Consistent original game art direction. Objects in rows 1 and 2 trees must be fully visible, large within their cells, with no cropped canopy. Smaller plants and rocks still centered inside their cells. Preserve true alpha transparency.

No gaps, no borders, no labels, no text, no objects, no horizon, no perspective, no diamond tiles. Orthographic top-down SURFACE TEXTURES only, designed to be sampled and projected onto isometric ground by a game engine. Beautiful crisp 16-bit pixel clusters, fine natural variation but not photographic noise, restrained saturation, consistent warm daylight. Rich premium pixel RPG environment texture art, visible square pixels, no gradient airbrush, no blur.
