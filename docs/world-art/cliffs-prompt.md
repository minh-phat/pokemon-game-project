# Cliff walls — imagegen

Generated using the built-in `image_gen` tool. Source: `apps/frontend/public/assets/world-v3/cliffs-source.png`. Runtime atlas: `cliffs.png` in the same directory. Each of the four materials is projected onto the actual vertical terrain faces in the renderer.

Use case: stylized-concept. Asset type: production cliff-wall texture atlas for an isometric pixel-art open-world game. Generate a square image divided into an exact 2 by 2 grid of four equal square texture panels, edge to edge, no gaps, no labels, no borders. These are FLAT FRONT-VIEW VERTICAL ROCK WALL SURFACES, not scenic landscapes, no perspective, no sky, no objects, no isolated rocks. Upper right: alpine granite cliff face, blue slate gray rock strata, angular fractures, occasional pale quartz seams. Lower left: frozen mountain cliff, silver-blue stone strata, thin vertical icy veins and compact snow caught on ledges. Lower right: volcanic basalt cliff, deep charcoal purple layered columnar stone, tiny restrained amber fissures. Art direction: beautiful handcrafted 16-bit pixel RPG environmental art; crisp deliberate square pixel clusters, restrained harmonious colors, dimensional light and shadow within cracks, subtle ambient warm light from upper left, fine details readable when reduced to small game tiles, uniformly distributed details suitable for repeating along a long cliff. The four textures fill their respective square quadrants completely. No gradients, no photographic noise, no blur, no text, no watermark. Each panel should remain a flat reusable wall texture, not a rendered mountain.
